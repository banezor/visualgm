VISUAL GIMMICK STUDIO — LANDING PAGE

Isi folder:
- index.html : struktur dan konten landing page
- style.css  : tampilan responsif untuk desktop, tablet, dan ponsel
- script.js  : menu ponsel, navigasi aktif, dan tahun otomatis

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder visual_gimmick_studio.
3. Klik dua kali index.html untuk membukanya di browser.
4. Koneksi internet diperlukan untuk Google Fonts dan foto dari Unsplash.

SEBELUM DIPUBLIKASIKAN
- Ganti email contoh hello@visualgimmickstudio.com dengan email resmi.
- Ganti tautan Instagram contoh dengan akun resmi.
- Ganti gambar/proyek contoh pada bagian Portofolio dengan karya yang benar-benar dimiliki.
- Sesuaikan daftar layanan dengan layanan aktual studio.
- Foto menggunakan URL Unsplash sehingga memerlukan koneksi internet.

CATATAN GOOGLE SITES
File HTML/CSS/JS ini adalah website mandiri, bukan file yang dapat diimpor langsung sebagai tema Google Sites. Untuk memakainya di Google Sites, konten perlu disusun ulang memakai editor Google Sites, atau website ini dapat di-host sebagai situs statis pada layanan hosting.
